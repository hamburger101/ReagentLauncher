# Reagent Launcher

Mods for your Steam, Epic Games and Xbox games as Off/On switches.

- Website: https://hamburger101.github.io/ReagentLauncher/
- Download: the newest release on the [Releases](https://github.com/hamburger101/ReagentLauncher/releases/latest) page

This branch holds the website, generated by `website/build_site.py` in the launcher's project;
edits made here are replaced by the next deploy. The launcher updates itself from this
repository's releases.
