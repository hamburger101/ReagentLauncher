# Reagent Launcher

Mods for your Steam, Epic Games and Xbox games as Off/On switches.

- Website: https://hamburger101.github.io/
- Download: the newest release on the [Releases](https://github.com/hamburger101/ReagentLauncher/releases/latest) page

The launcher updates itself from this repository's releases. The website moved to
https://hamburger101.github.io/ - this branch only sends visitors of the old address
there (generated by `website/build_site.py`; edits made here are replaced by the next deploy).
